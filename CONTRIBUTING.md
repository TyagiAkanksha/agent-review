# Contributing

Issues and pull requests are welcome.

- **A finding that was wrong?** Open an issue with the tool definition and the finding. If the pattern is fine in general, it belongs in `references/calibration.md`.
- **A new check?** Add it to `references/checklist.md` with an ID, default severity and a source link, then reference it from the skill that runs it.
- **Spec changes.** The checklist is pinned to one MCP spec revision. A PR that moves it to a new revision should note which defaults or rules changed.

Keep wording original. Link to sources; don't copy passages from them.
